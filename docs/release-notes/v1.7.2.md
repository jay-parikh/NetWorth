# Room for a hundred fixed deposits

The Fixed Deposits tab used to save 50 rows. If you ladder FDs across a
family, 50 runs out — and the updater would stop with *"holds 54 rows but
the sheet can only save 50"* rather than quietly drop the extra ones.

**The tab now saves 100 FDs.** Nothing else changes: your existing rows,
totals and returns are exactly as they were, and the update simply runs.

Refusing to run was the right behaviour — losing a deposit you typed
would be far worse than an evening's inconvenience — but the limit itself
was too low. If you ever reach 100, the updater will say so just as
plainly, and the same fix applies: tell us and we'll raise it.
